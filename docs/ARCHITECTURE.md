# OpenSight 3.1 架构与安全规范

## 子系统严格隔离规则
1. **Core 子系统:**
   - 纯粹的本地计算与 Direct Socket 探测引擎。
   - 严禁调用任何 subprocess，严禁导入 VPN 核心，严禁私自建立 VPN 隧道。
2. **VPN 子系统:**
   - 负责与已审计的 OpenVPN 进程通信，所有连接参数经过强制白名单校验。
   - 绝不伪造二进制执行，遇到异常坚决退出并回滚。
3. **UI 子系统:**
   - 基于 React 前端与 Tauri 原生宿主容器，通过安全本地 REST/WebSocket 与 Core API 进行进程间通信。
   - 具备独立自动化进程冒烟与网络健康度自检机制。
